Why GitHub?

GitHub is where most of the world's software lives. Companies use it to store code, track every change, and work together. GitHub Pages turns a folder of HTML into a live website for free.

You'll leave this module with a public link to sites you built, plus a history of every change you made.

Start here (do this once)

  1. Create a GitHub account at github.com/signup. Your username shows up in your web address, so pick something professional.
  2. Copy the starter files. Click the button below, then Create a new repository.
    • Repository name: bmis235 (exactly this)
    • Set it to Public

    Use the starter templateView the starter files

  3. Turn on GitHub Pages. In your new repo, go to Settings → Pages. Under Build and deployment, choose Deploy from a branch, pick main and / (root), then click Save.
  4. Check that it works. After 1–2 minutes, open https://YOUR-GITHUB-USERNAME.github.io/bmis235/assignment1/. If you see "Hello World!", you're set.
    Seeing a 404? Your first site can take up to 5 minutes. Settings → Pages says Your site is live when it's ready.

Your site is public. Anyone with the link can see it. Don't post anything you wouldn't want an employer to see.

How you'll edit (HTML-1 to HTML-4)

  1. In your repo, click into an assignment folder, then click the file (for example index.html).
  2. Click the pencil icon to edit it in the browser.
  3. Make a change, then click Commit changes. Write a short message saying what you changed.
  4. Wait 1–2 minutes and refresh your live link.

To add an image: open the assignment folder, click Add file → Upload files, drop the image in, and commit.

Use the pencil editor for HTML-1 to HTML-4. You'll learn more by working through the code yourself. In HTML-5 you'll unlock the full editor.

Make it yours (every assignment)

  • Fill in the author comment at the top of every file with your name and GU username.
  • Fill in <meta name="author"> with your name.
  • Fill in the footer: Built by YOUR NAME · BMIS 235.
  • Make at least 3 commits with clear messages (not "Update index.html").

Each assignment also has personal choices that only you would make. Work missing the author comment or footer will be returned ungraded.

The #1 bug: upper and lower case

On GitHub Pages, Photo.JPG and photo.jpg are different files. If an image won't show up, check that the name in your code matches the file name exactly, letter for letter.
