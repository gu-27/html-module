Why GitHub?

GitHub is where most of the world's software lives. Companies use it to store code, track every change, and work together. GitHub Pages turns a folder of HTML into a live website for free.

You'll leave this module with public links to sites you built, plus a history of every change you made.

Start here (do this once)

  1. Create a GitHub account at github.com/signup. Your username shows up in your web addresses, so pick something professional.
  2. That's it for now. Each assignment has its own starter. You'll get it from the assignment's page when it's released. The page walks you through copying the starter and turning on GitHub Pages.

Your sites are public. Anyone with the link can see them. Don't post anything you wouldn't want an employer to see.

How you'll edit (HTML-1 to HTML-3)

  1. In your repo, click the file you want to change (for example index.html).
  2. Click the pencil icon to edit it in the browser.
  3. Make a change, then click Commit changes. Write a short message saying what you changed. A commit is a saved version. You can always go back to it.
  4. Wait 1–2 minutes and refresh your live link.

To add an image: on your repo's main page, click Add file → Upload files, drop the image in, and commit.

Use the pencil editor for HTML-1 to HTML-3, with no AI. You'll learn more by working through the code yourself. In the final (HTML-4) you'll unlock the full editor and AI.

Make it yours (every assignment)

  • Fill in the author comment at the top of every file with your name and GU username.
  • Fill in <meta name="author"> with your name.
  • Fill in the footer: Built by YOUR NAME · BMIS 235.
  • Make at least 3 commits with clear messages (not "Update index.html").

Each assignment also has personal choices that only you would make. Work missing the author comment or footer will be returned ungraded.

The #1 bug: upper and lower case

On GitHub Pages, Photo.JPG and photo.jpg are different files. If an image won't show up, check that the name in your code matches the file name exactly, letter for letter.
