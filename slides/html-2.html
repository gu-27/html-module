Color lives in code, in two places

A style block, at the top

Inline, on one tag

Changes only that tag.

The question to ask

For everything on a page: who controls it?

Four ways content gets on a page

You control it

Owned

A file in your folder, like fridman.jpg. It only changes when you change it.

They control it

Linked

A file on someone else's site, pointed to by its address. They can move or delete it.

They control it

Embedded

A live window into another service: YouTube, a map, a dashboard. It runs on their end.

You control it

Built

Code in your page that does something, like a dark mode button.

Owned, linked and embedded are about what a page shows. Built is about what it does.

An embed is a little browser tab cut into your page

Press → to step · your page is never in the middle

Every embed is a window. They differ in what you can do in it.

Static

Just shows something.

A slideshow, a social post, a picture of a chart

Interactive

Your clicks change your own view. Nothing is saved.

Play and pause a video, filter a dashboard, zoom a map

Two-way

You send information and they keep it.

A form, a booking calendar, a checkout button

Live is a separate question: does it update on its own? Any of the three can be live. A dashboard can be interactive and live.

Borrowing is easy. It isn't free.

It can vanish

If they move or delete it, a hole appears in your page.

It's slower

Every embed is another site loading inside yours.

They see your visitors

The other company knows who loaded it. That's why YouTube embeds bring cookies.

It has a fixed size

Embed code comes with a width and height, so on a phone it can spill off the screen.

The script · try changing the two colors
Click the button

The dark mode code, line by line

// 1. Your two colors var lightColor = "#f2f2f2"; var darkColor = "#222222"; // 2. Which mode we're in var dark = false; // 3. Page one color, block the other function paint() { var pageColor = dark ? darkColor : lightColor; var blockColor = dark ? lightColor : darkColor; document.body.style.backgroundColor = pageColor; …the block gets blockColor } // 4. On click: flip, then repaint function toggleDark() { dark = !dark; paint(); } // 5. Paint once at the start paint();
var makes a labeled box that holds a value. These two are the only lines you change.
dark remembers the mode: false is light, true is dark.
a ? b : c means "if a, use b, otherwise c". The block always gets the opposite color.
!dark means "not dark", so each click flips it. Then it repaints.
A function only runs when called. This line calls it once, so the page starts colored.

HTML-2's usual suspects

  1. Broken picture? Compare the src to the file name, letter by letter. Capitals count.
  2. Click jumps nowhere? The #name must match the id exactly.
  3. "Refused to connect"? Use /embed/ABC, not watch?v=ABC.
  4. Embed block still empty? Paste the whole code, <iframe to </iframe>.
  5. Still stuck? "I expected ___, but I see ___." Search that.

No live link on Settings → Pages?

When it works, the top of that page says "Your site is live at…" with your link. No link means GitHub hasn't built your site. Check in this order:

  1. Source says "Deploy from a branch"? Not "GitHub Actions". Pick main and / (root), then Save.
  2. Email verified? Go to github.com/settings/emails. "Unverified" means click Resend, then verify.
  3. Actions allowed? Settings → Actions → General → Allow all actions → Save.
  4. Kick it: edit one word in README.md, commit, wait 2 minutes, refresh Settings → Pages.
  5. Still no link? Check the Actions tab for a red X, then show me.

Save button won't save?

On Settings → Pages, Save only lights up after you change something. Work down this list:

  1. Branch says "None"? Click it, pick main first. Then the folder box appears: pick / (root). Now click Save.
  2. Already says main and / (root), Save is gray? It's already saved. Nothing to click. Go to the "No live link?" checks.
  3. No "main" in the list? Your repo is empty. Make it again with Use this template.
  4. Clicking does nothing? Hard-refresh (Ctrl+Shift+R / Cmd+Shift+R), or try a private window or another browser. Ad blockers can break GitHub's buttons.
  5. Still stuck? Check the repo is Public and you're signed in as its owner.
