You type an address. Your browser asks a server for the files. The server sends them. Your browser draws them.

2 · A website is just files in folders

my-site/
   index.html      ← the home page
   about.html      ← another page
   photo.jpg       ← an image
   styles.css      ← the look

Every page is a text file. Every image is a file. The web address is the path to the folder.

3 · Hosting

Putting your folder on a computer anyone can reach

Your laptop turns off. A server doesn't. Hosting means copying your folder to a server that's always on, with an address that points to it.

4 · GitHub

  • Repo: a folder of files that lives on GitHub.
  • Commit: a saved version with a note. "Save as" that never forgets.
  • History: every commit, in order. Your undo button.

6 · Tags

<h1>Hello World!</h1>
  • Opening tag, content, closing tag.
  • The closing tag has a /.
  • The browser shows the content, not the tags.

7 · Attributes

<img src="earth.jpg" alt="Earth from space">
  • Extra details inside the opening tag.
  • Always name="value", in quotes.
  • src is where the image is. alt describes it.

8 · head and body

<head>

About the page. The tab title, the colors. Nothing here shows on the page itself.

<body>

What people see. Headings, text, images, links.

<title>Jane's Page</title>   ← shows on the browser tab

9 · Headings, paragraphs, bold, italic

<h2>Smaller heading</h2>

No live link on Settings → Pages?

When it works, the top of that page says "Your site is live at…". No link means GitHub hasn't built your site yet. Check in order:

  1. Source says Deploy from a branch (not "GitHub Actions"), with main and / (root). Save.
  2. Email verified at github.com/settings/emails.
  3. Settings → Actions → General → Allow all actions. Save.
  4. Edit one word in README.md, commit, wait 2 minutes, refresh.
  5. Still nothing? Look for a red X on the Actions tab and show your professor.

Save button won't save?

On Settings → Pages, Save only lights up after you change something. Work down this list:

  1. Branch says "None"? Pick main first, then / (root), then Save.
  2. Already main and / (root), Save is gray? It's already saved. Go to the "No live link?" checks.
  3. No "main" in the list? Your repo is empty. Make it again with Use this template.
  4. Clicking does nothing? Hard-refresh, or try a private window or another browser. Ad blockers can break GitHub's buttons.
  5. Still stuck? Check the repo is Public and you're signed in as its owner.

When you're stuck

  1. Say it in one sentence: "I expected ___, but I see ___."
  2. Pick one problem.
  3. Find the line.
  4. Search your one sentence.
  5. Change one thing. Commit. Check.

"Nothing works" can't be searched. "My image shows a broken icon" can.
