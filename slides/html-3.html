1 · Links between your own pages

<a href="alex.html">Alex</a>

Just the file name, because it's in the same folder. Put the same menu on every page and your site has navigation.

2 · Outside links and email links

<a href="https://www.gonzaga.edu">Gonzaga</a>

<a href="mailto:you@zagmail.gonzaga.edu">Email me</a>
  • Outside links need the full address with https://.
  • mailto: opens the reader's email app.

3 · File names and links must match

You renamepage2.html → alex.html
→
Every menu still sayshref="page2.html"
→
404 on four pages

Rename a file, then fix its link on every page. Exact spelling, exact case.

4 · Three ways to add CSS

External

One .css file. Every page links to it.

Internal

A <style> block in one page's head.

Inline

style="..." on one tag.

HTML-1 and HTML-2 used internal. HTML-3 uses external.

5 · Why one stylesheet wins

Style each page

Change the menu color? Edit 4 pages. Miss one and the site looks broken.

One stylesheet

Change the menu color? Edit 1 line. All 4 pages change.

Real sites have hundreds of pages. Nobody styles them one at a time.

6 · The one line that connects them

<head>
   <title>Home</title>
   <link rel="stylesheet" href="styles.css">
</head>

No link, no style. A page that looks plain is usually missing this line.

7 · Plan on paper first

Our House          index.html
Alex               alex.html
Priya              priya.html
House rules        rules.html

Four page names, four file names, before you type anything. Lowercase, no spaces, .html at the end. Simplify before you start.
