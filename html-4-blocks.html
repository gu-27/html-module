How to use a block

  1. Pick a block below. Look at the preview.
  2. Copy its HTML. Open the page where you want it, click the pencil, and paste it inside the <body>, where it should appear. Commit.
  3. Copy its CSS. Open styles.css, paste it at the very bottom. Commit.
  4. Now make it yours: change the words, swap img/sample-1.jpg for your own photos, write real alt text, and change the colors to your brand. Commit.
  5. The sample photos only live on this page, so on your site they'll show as broken images at first. That's your cue: upload your own photos into img and change each src to match.

What's happening: each block is two halves, like every page you've built. The HTML is what shows up; the CSS is how it looks. Every class name starts with blk- so the block's styles only touch the block, not your menu or headings. Paste the HTML without the CSS and it still works, it just looks plain, exactly like your unlinked page in HTML-3.

Banner

A big opening section at the top of a page: a headline, one line under it, and a button.

1 · HTML paste into a page's <body>, where you want it

<!-- BANNER: big opening section -->
<section class="blk-banner">
    <h2>Welcome to Our House</h2>
    <p>Four roommates. One house. Meet us below.</p>
    <a class="blk-button" href="susie.html">Meet Susie</a>
</section>

2 · CSS paste at the bottom of styles.css

/* BANNER */
.blk-banner {
    background-color: #2b5d8c;   /* change to your brand color */
    color: white;
    text-align: center;
    padding: 60px 20px;
    border-radius: 12px;
    margin: 20px auto;
    max-width: 900px;
}
.blk-banner h2 { font-size: 40px; margin: 0 0 10px 0; }
.blk-banner p { font-size: 20px; margin: 0 auto 24px auto; }
.blk-button {
    display: inline-block;
    background-color: white;
    color: #2b5d8c;              /* same brand color */
    padding: 12px 24px;
    border-radius: 8px;
    font-weight: bold;
    text-decoration: none;
}

Cards

Three boxes side by side, each with a picture, a title and a few words. They stack on a phone.

1 · HTML paste into a page's <body>, where you want it

<!-- CARDS: three boxes side by side -->
<div class="blk-cards">
    <div class="blk-card">
        <img src="img/sample-1.jpg" alt="Describe photo 1">
        <h3>Susie</h3>
        <p>Studies finance. Runs before sunrise.</p>
    </div>
    <div class="blk-card">
        <img src="img/sample-2.jpg" alt="Describe photo 2">
        <h3>Alex</h3>
        <p>Studies marketing. Cooks every Sunday.</p>
    </div>
    <div class="blk-card">
        <img src="img/sample-3.jpg" alt="Describe photo 3">
        <h3>Jordan</h3>
        <p>Studies MIS. Owns 40 plants.</p>
    </div>
</div>

2 · CSS paste at the bottom of styles.css

/* CARDS */
.blk-cards {
    display: flex;
    flex-wrap: wrap;             /* lets the cards stack on a phone */
    gap: 20px;
    justify-content: center;
    margin: 30px auto;
    max-width: 900px;
}
.blk-card {
    flex: 1 1 240px;
    background-color: white;
    border: 2px solid #dddddd;
    border-radius: 12px;
    overflow: hidden;
    text-align: center;
}
.blk-card img { width: 100%; height: 160px; object-fit: cover; }
.blk-card h3 { margin: 14px 0 6px 0; }
.blk-card p { margin: 0 16px 18px 16px; }

Photo gallery

A grid of photos with a short caption under each one.

1 · HTML paste into a page's <body>, where you want it

<!-- GALLERY: grid of photos with captions -->
<div class="blk-gallery">
    <figure>
        <img src="img/sample-1.jpg" alt="Describe photo 1">
        <figcaption>Move-in day</figcaption>
    </figure>
    <figure>
        <img src="img/sample-2.jpg" alt="Describe photo 2">
        <figcaption>Sunday dinner</figcaption>
    </figure>
    <figure>
        <img src="img/sample-3.jpg" alt="Describe photo 3">
        <figcaption>Game night</figcaption>
    </figure>
</div>

2 · CSS paste at the bottom of styles.css

/* GALLERY */
.blk-gallery {
    display: grid;
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    gap: 16px;
    margin: 30px auto;
    max-width: 900px;
}
.blk-gallery figure { margin: 0; }
.blk-gallery img {
    width: 100%;
    height: 180px;
    object-fit: cover;           /* crops photos to the same shape */
    border-radius: 10px;
}
.blk-gallery figcaption { text-align: center; font-size: 15px; margin-top: 6px; }

Table

Rows and columns for anything you'd put in a spreadsheet: a schedule, prices, a comparison.

1 · HTML paste into a page's <body>, where you want it

<!-- TABLE: rows and columns -->
<table class="blk-table">
    <tr>
        <th>Chore</th>
        <th>Who</th>
        <th>When</th>
    </tr>
    <tr>
        <td>Dishes</td>
        <td>Alex</td>
        <td>Every night</td>
    </tr>
    <tr>
        <td>Trash</td>
        <td>Jordan</td>
        <td>Tuesday</td>
    </tr>
    <tr>
        <td>Groceries</td>
        <td>Susie</td>
        <td>Saturday</td>
    </tr>
</table>

2 · CSS paste at the bottom of styles.css

/* TABLE */
.blk-table {
    border-collapse: collapse;   /* removes the double lines */
    margin: 30px auto;
    width: 100%;
    max-width: 600px;
}
.blk-table th {
    background-color: #2b5d8c;   /* your brand color */
    color: white;
    text-align: left;
}
.blk-table th, .blk-table td { padding: 10px 14px; border-bottom: 1px solid #dddddd; }
.blk-table tr:nth-child(even) td { background-color: #f2f2f2; }  /* stripes */

Questions and answers

Questions people can click to open the answer. No code needed to make it open: the browser does it.

1 · HTML paste into a page's <body>, where you want it

<!-- FAQ: click a question to open the answer -->
<div class="blk-faq">
    <details>
        <summary>Can I visit?</summary>
        <p>Yes. Text first, and bring snacks.</p>
    </details>
    <details>
        <summary>Who does the dishes?</summary>
        <p>Alex, every night. Check the chore table.</p>
    </details>
    <details>
        <summary>Is there parking?</summary>
        <p>Street parking only.</p>
    </details>
</div>

2 · CSS paste at the bottom of styles.css

/* FAQ */
.blk-faq { max-width: 600px; margin: 30px auto; }
.blk-faq details {
    border: 2px solid #dddddd;
    border-radius: 10px;
    padding: 12px 16px;
    margin-bottom: 10px;
    background-color: white;
}
.blk-faq summary { font-weight: bold; cursor: pointer; }
.blk-faq p { margin: 10px 0 0 0; }

Contact

A closing box with an email link and links to other sites.

1 · HTML paste into a page's <body>, where you want it

<!-- CONTACT: email and outside links -->
<div class="blk-contact">

        <a href="https://www.gonzaga.edu">Gonzaga</a> &middot;

    </p>
</div>

/* CONTACT */
.blk-contact {
    text-align: center;
    background-color: #f2f2f2;
